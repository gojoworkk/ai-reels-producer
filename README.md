# AI Reels Producer

Находит взлетевшие рилсы конкурентов и превращает их в готовые сценарии на русском.

**Найти → переписать → отдать.**

1. **Конкуренты.** Вставляете Instagram-аккаунт (например, американского блогера). Приложение через Apify забирает его последние 20 рилсов (больше не берём, чтобы не тратить лимиты).
2. **Главная.** Все скачанные рилсы в одном рейтинге. Место определяет «залёт»: во сколько раз просмотры рилса выше медианы по последним 20 рилсам аккаунта. Так рилс маленького блогера с ×15 окажется выше рилса миллионника с ×1.2.
3. **Страница рилса.** Кнопка «Создать сценарий» достаёт транскрипт рилса (Apify) и отдаёт его Claude. Claude не переводит дословно, а адаптирует текст для русскоязычной аудитории: живой разговорный язык, замена идиом и культурных отсылок, сохранение механики хука. Сценарий разбит на блоки: идея, почему залетело, хук, основная часть, призыв к действию и описание к посту. Карандаш включает редактирование, «Смотреть оригинал» открывает видео.

Дизайн повторяет Notion: чёрно-белая палитра и тёмная тема по системной настройке.

## Запуск локально

Нужен Node.js 20.9+.

```bash
npm install
cp .env.example .env.local   # и вписать ключи
npm run dev
```

Откройте http://localhost:3000.

### Ключи

| Переменная | Где взять | Зачем |
| --- | --- | --- |
| `APIFY_TOKEN` | [console.apify.com → Settings → Integrations](https://console.apify.com/settings/integrations) | Скачивание рилсов ([apify/instagram-reel-scraper](https://apify.com/apify/instagram-reel-scraper)) и транскриптов |
| `ANTHROPIC_API_KEY` | [platform.claude.com → API keys](https://platform.claude.com/settings/keys) | Написание сценариев (модель `claude-opus-5-5`) |

Транскрипт у Apify оплачивается поминутно, поэтому его берём только для рилса, по которому создаётся сценарий, а не для всех 20.

### Демо без ключей

```bash
npm run seed:demo
```

Создаёт аккаунт `demo_account` с 8 рилсами и одним готовым сценарием. Удалить его можно корзиной на странице «Конкуренты».

## Устройство

```
src/
  app/
    page.tsx              — Главная: рейтинг всех рилсов
    competitors/page.tsx  — Конкуренты: добавление и обновление аккаунтов
    reels/[id]/page.tsx   — Страница рилса со сценарием
    actions.ts            — Server Actions: загрузка рилсов, генерация и сохранение сценария
  lib/
    apify.ts              — Клиент Apify
    scriptwriter.ts       — Промпт и вызов Claude (structured output)
    db.ts                 — Хранилище в data/db.json
  components/             — UI в стиле Notion
```

Данные лежат в `data/db.json` (файл не попадает в git). Для MVP этого хватает; для работы в облаке хранилище нужно заменить на Postgres.

Стек: Next.js 16 (App Router, Cache Components), React 19, Tailwind CSS 4, Anthropic SDK.
