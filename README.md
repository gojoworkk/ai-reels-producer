# Reels Finder — ИИ Рилс Продюсер

Находит взлетевшие рилсы конкурентов и превращает их в готовые сценарии на русском.

## Как устроено внутри

```
1. Источник данных        2. Front-end              3. API + Back-end           4. База и хранилище
──────────────────        ─────────────             ─────────────────           ───────────────────
Instagram конкуренты  →   Next.js (порт 3000)  ⇄    FastAPI (порт 8000)    ⇄    PostgreSQL 17
        ↓                 · Конкуренты         HTTP · REST эндпоинты            конкуренты, reels, тексты
      Apify               · Главное            JSON · бизнес-логика               (хук, скрипт, CTA), теги,
· последние 20 рилсов     · Карточка рилса          · аутентификация              комментарии, статусы, события
· видео, описания,                                  · запись в БД и хранилище
  метаданные                                        · статусы задач             Файловое хранилище
· расписание (каждые N ч)                           · Claude: сценарий          обложки, видео, превью-кадры,
                                                                                экспорты (pdf / md / txt / csv), tmp
```

**Сквозной процесс**

1. Пользователь добавляет конкурента на экране «Конкуренты».
2. Apify достаёт его последние 20 рилсов.
3. Бэкенд нормализует данные и считает «залёт»: во сколько раз просмотры выше медианы аккаунта.
4. Данные пишутся в PostgreSQL, обложки, видео и кадры — в файловое хранилище.
5. Front-end показывает рейтинг рилсов на «Главном».
6. Пользователь жмёт Remix: бэкенд берёт транскрипт через Apify, Claude адаптирует сценарий на русский. Текст можно править в карточке рилса.
7. Бэкенд сохраняет изменения.
8. Обновлённые данные снова отображаются в приложении.

Долгие операции (загрузка рилсов, написание сценария) идут фоновыми задачами. Интерфейс показывает их прогресс по шагам.

**Что есть что**

| Часть | Где | Что делает |
| --- | --- | --- |
| Front-end | `src/` | Интерфейс на Next.js: экраны «Главное», «Конкуренты», «Карточка рилса» |
| Back-end | `backend/app/` | FastAPI: обрабатывает запросы, управляет данными, запускает задачи |
| API | `backend/app/routers/` | REST-мост между интерфейсом и сервером. Документация: http://localhost:8000/docs |
| БД | PostgreSQL, `backend/app/models.py` | Структурированные данные в таблицах |
| Хранилище | `backend/storage/` | Тяжёлые файлы: видео, изображения, экспорты |

## Запуск

Нужны Node.js 20.9+ и Python 3.10+.

```bash
npm install
npm run setup
```

`setup` создаёт Python-окружение бэкенда и файлы `.env`. На Windows он сам скачивает PostgreSQL 17 в папку `.tools/` (~340 МБ, без установки в систему). На macOS и Linux поставьте PostgreSQL сами, например `brew install postgresql@17`.

Впишите ключи в `backend/.env`:

| Переменная | Где взять | Зачем |
| --- | --- | --- |
| `APIFY_TOKEN` | [console.apify.com → Settings → Integrations](https://console.apify.com/settings/integrations) | Рилсы и транскрипты ([apify/instagram-reel-scraper](https://apify.com/apify/instagram-reel-scraper)) |
| `ANTHROPIC_API_KEY` | [platform.claude.com → API keys](https://platform.claude.com/settings/keys) | Сценарии (модель `claude-opus-5-5`) |

Затем:

```bash
npm run dev
```

Одна команда поднимает PostgreSQL, API и сайт. Сайт: http://localhost:3000, API: http://localhost:8000/docs.

### Полезные команды

| Команда | Что делает |
| --- | --- |
| `npm run db:seed` | Демо-аккаунт с 8 рилсами и готовым сценарием — посмотреть интерфейс без ключей |
| `npm run db:stop` | Остановить PostgreSQL (`npm run dev` его не гасит, чтобы следующий запуск был быстрее) |
| `npm run dev:web` / `npm run dev:api` | Запустить только сайт или только API |

### Настройки бэкенда (`backend/.env`)

| Переменная | По умолчанию | Смысл |
| --- | --- | --- |
| `SYNC_INTERVAL_HOURS` | `24` | Автообновление всех конкурентов через Apify. `0` — выключено. Каждое обновление тратит лимиты Apify |
| `API_TOKEN` | генерируется | Общий секрет: front-end подписывает им запросы к API. Тот же токен лежит в `.env.local` |
| `DATABASE_URL` | локальный PostgreSQL на порту 5433 | Можно указать облачную базу, например Neon |

Транскрипт у Apify оплачивается поминутно, поэтому его берём только для рилса, по которому пишется сценарий, а не для всех 20.

## API

Все запросы, кроме `/api/health`, требуют заголовок `Authorization: Bearer <API_TOKEN>`.

| Метод | Путь | Что делает |
| --- | --- | --- |
| GET | `/api/competitors` | Конкуренты со статистикой и статусом загрузки |
| POST | `/api/competitors` | Добавить конкурента и запустить загрузку 20 рилсов |
| POST | `/api/competitors/{ник}/sync` | Загрузить свежие рилсы |
| DELETE | `/api/competitors/{ник}` | Удалить вместе с рилсами и файлами |
| GET | `/api/reels?account=` | Рейтинг рилсов |
| GET | `/api/reels/{id}` | Карточка рилса: сценарий, комментарии, превью |
| POST | `/api/reels/{id}/script` | Создать сценарий или Remix (фоновая задача) |
| PATCH | `/api/reels/{id}/script` | Сохранить правки блока |
| POST | `/api/reels/{id}/comments` | Комментарий к хуку, скрипту или CTA |
| GET | `/api/reels/{id}/export?format=pdf\|md\|txt` | Экспорт сценария |
| GET | `/api/export/reels.csv` | Таблица рилсов для Excel |
| GET | `/api/jobs/{id}` | Статус и прогресс фоновой задачи |
| GET | `/api/events` | Журнал событий |

Таблицы создаются при первом запуске API. Стек: Next.js 16, React 19, Tailwind CSS 4 · FastAPI, SQLAlchemy 2, PostgreSQL 17, APScheduler, ffmpeg (кадры-превью), fpdf2 (PDF) · Anthropic SDK, Apify.
